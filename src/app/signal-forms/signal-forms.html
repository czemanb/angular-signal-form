Signal Forms – 2. lépés: beépített validátorok és hibaüzenetek

A form() második argumentuma a schema-függvény. Deklaratív validátorok — required, email, minLength. A hibák field().errors() signalból jönnek; csak touched() után mutatjuk őket. Egy mezőn több hiba is létezhet egyszerre.

@if (f.email().touched()) { @for (e of f.email().errors(); track e.kind) { {{ e.message }} } }
@if (f.password().touched()) { @for (e of f.password().errors(); track e.kind) { {{ e.message }} } }
