Migráció – fokozatos átállás Signal Formsra

Két stratégia a meglévő kód és az új Signal Forms kombinálásához. Mindkettő éles, production-ready Angular 22-ben.

A: Top-down — compatForm

A jelszó egy meglévő FormControl komplex vállalati validátorokkal (min 8 karakter, nagybetű + szám). Nem írjuk újra — a compatForm beágyazza a signal modellbe. Az e-mail mező új, signal validátorral. A f().valid() mindkét mezőt számolja.

signal({ email: '', password: legacyCtrl }) → compatForm(model, schema) → extractValue(f)
@if (topDownForm.email().touched()) { @for (e of topDownForm.email().errors(); track e.kind) { {{ e.message }} } }
@if (topDownForm.password().touched()) { @for (e of topDownForm.password().errors(); track e.kind) { {{ compatMessage(e.kind) }} } } Formátum: min 8 kar., legalább 1 nagybetű + 1 szám (pl. Password1)
@if (topDownSubmitted(); as data) {
extractValue() eredménye: 
{{ data | json }}
}

B: Bottom-up — SignalFormControl

A meglévő FormGroup változatlan. Csak az e-mail mező lett SignalFormControl — ez extends AbstractControl, ezért a form.valid, markAllAsTouched(), stb. változatlan. A sablonban [formField]="emailCtrl.fieldTree" adja a signal-os kötést, a jelszó marad formControlName-mel.

new SignalFormControl('', schema) → new FormGroup({ email: emailCtrl, password: new FormControl(...) }) → [formField]="emailCtrl.fieldTree"
